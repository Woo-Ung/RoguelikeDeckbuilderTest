# Plan Template

> 프로젝트 신규 개발 또는 대규모 기능 추가 시 작성하는 프로젝트 계획서 양식.

> 해당하지 않는 선택 항목은 생략.

> 사용자의 명시적인 명령 외에는 해당 양식을 기반으로 계획을 작성한다.

## Plan 작성 규칙

> Plan 작성 시 아래 `계획 작성 템플릿`의 구성에 따라 작성
