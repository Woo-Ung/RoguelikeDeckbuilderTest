# Coding Conventions

## Naming
- 클래스, 메서드, 프로퍼티: PascalCase
- 지역 변수, 매개변수: camelCase
- private / protected 필드: _camelCase
- 인터페이스: I 접두사 사용
- 상수: PascalCase

## Code Style
- 중괄호는 새로운 줄에서 시작
- 접근 제한자 명시
- 의미가 명확한 변수 및 메서드 이름 사용
- 메서드별 단일 책임 원칙 준수
- 기존 코드 수정 시 해당 코드의 스타일 우선

## Comments
- 역할이나 의도에 대한 추가 설명이 필요한 필드와 메서드에 `//` 주석 작성
- 주석은 해당 필드 또는 메서드 선언 바로 위에 배치
- 주석은 한국어로 간결하게 작성
- 구현 과정보다는 역할과 의도 중심으로 작성
- 코드 변경 시 관련 주석 동기화
- 불필요하게 중복되는 설명 지양
- 일반 주석은 `//` 사용, API 문서화가 필요한 경우 `///` 허용
